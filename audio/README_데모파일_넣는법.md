# Before/After 데모 파일 넣는 법

이 폴더에 아래 두 파일을 넣으면 믹싱 페이지에 "귀로 확인하세요" A/B 플레이어 섹션이 자동으로 나타납니다.
(파일이 없으면 섹션은 숨겨진 상태라 사이트에 아무 영향 없음)

- `demo1_before.mp3` — 믹싱 전 (러프 믹스/원본)
- `demo1_after.mp3`  — 믹싱·마스터링 후 (최종본)

## 팁
- 두 파일은 **같은 곡, 같은 길이**여야 A/B 전환이 자연스러움
- 풀곡 말고 **하이라이트 30~40초**만 잘라서 (저작권 + 로딩속도)
- 음량 차이가 드라마틱하게 들리도록 before는 마스터링 안 된 상태 그대로
- mp3 192kbps 정도면 충분 (파일당 1MB 내외)
